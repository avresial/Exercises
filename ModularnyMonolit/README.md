# 🧩 Modularny Monolit — DevMentors

Repozytorium zawiera mój kod, notatki i eksperymenty realizowane w trakcie kursu **"Modularny Monolit"** od [DevMentors](https://devmentors.io/).  
Celem projektu jest praktyczne poznanie zasad budowy aplikacji o architekturze **modularnego monolitu** z wykorzystaniem nowoczesnych wzorców i narzędzi .NET.

---

## 🧠 Cele nauki

- Zrozumienie architektury modularnego monolitu.  
- Praktyczne zastosowanie **DDD (Domain-Driven Design)**.  
- Poznanie wzorców **CQRS**, **Event-Driven Architecture** i **Clean Architecture**.  
- Budowa skalowalnej, łatwej w utrzymaniu aplikacji backendowej.  
- Praca z popularnymi narzędziami i bibliotekami .NET (m.in. ASP.NET Core, EF Core, Mediatr, Serilog, RabbitMQ).
